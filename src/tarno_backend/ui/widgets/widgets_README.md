# `tarno_backend/ui/widgets/` — legacy PySide6 control-window widgets

⚠️ Part of the deprecated `ui/` stack — see [`ui_README.md`](../ui_README.md)
(TD-006) for why and what replaces it (`src/TARNO.UI/`).

## Files

- **`chat_area.py`**: chat area widget for the control window.
- **`log_view.py`**: log view widget for the control window.
- **`mic_button.py`**: microphone / mute button widget.
- **`status_bar.py`**: status bar widget for the control window.

Note: `tarno_backend/gui/widgets/status_bar.py` is a *different* file with
the same name in the *other* deprecated UI stack (`gui/`, BuildMC-styled) —
not a duplicate/mistake, just two independent legacy stacks that happened
to name a file the same way.
